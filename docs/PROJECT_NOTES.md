# Project Notes

## Design direction
NovaSocial is intentionally inspired by the interaction patterns of modern photo-sharing platforms, but uses its own name, visual identity, CSS, layout implementation and assets.

## Why this structure
The CodeAlpha task requires a real full-stack social media application. The frontend therefore communicates with a Node.js/Express API, while MongoDB persists users, posts, comments and notifications.

## Local setup
MongoDB must be available before starting the server.

## Important
The seed script resets the NovaSocial database and should be used only for a local demo database.
